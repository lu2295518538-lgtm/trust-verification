07 / VC·VP

可验证凭证与隐私披露

W3C VC/VP · P-256 Pedersen 承诺 · Schnorr 零知识证明

本系统依据 DID_test 参考实现的密码学构造：VC 将元数据按 basic / ownership / content 三模块组织， 计算三元组哈希 x = SHA256(metadata ‘ fingerprint ‘ DID)，生成 P-256 上的 Pedersen 承诺 C = x·G + r·H；VP 可携带承诺点 (Cx, Cy) 与可选 Schnorr 零知识证明， 实现「全披露」或「零知识选择性披露」。签发者仍由 CA 信任锚用 SM2 签名问责。

08 / 签发者目录

签发者可信体系（CA）

根 CA → 签发者证书 · 绑定 DID / 统一社会信用代码 / 公钥 · 含有效期与吊销

演示：吊销某签发者后，回到「VC·VP」重新验证其签发的 VC/VP，将显示「签发者证书已被吊销」。吊销可逆，可随时「恢复」。

外部商业 CA 信任锚（联邦）

外部商业 CA 作为额外信任锚：其「成员」列表中的签发者，即使本信任锚未直接注册，验证时也会被认可为外部授信（状态 external）。停用后授信立即失效。外部 CA 根密钥仅展示指纹，不进入签名域。

主体 → CA 强绑定概览

统一命名空间 did:trust:livestock:party:<issuer_id>:<short>：背书签发机构直接编码进 DID，信任锚验签即强绑定
