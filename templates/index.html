07 / VC·VP

可验证凭证与隐私披露

W3C VC/VP · P-256 Pedersen 承诺 · Schnorr 零知识证明

本系统依据 DID_test 参考实现的密码学构造：VC 将元数据按 basic / ownership / content 三模块组织， 计算三元组哈希 x = SHA256(metadata ‘ fingerprint ‘ DID)，生成 P-256 上的 Pedersen 承诺 C = x·G + r·H；VP 可携带承诺点 (Cx, Cy) 与可选 Schnorr 零知识证明， 实现「全披露」或「零知识选择性披露」。签发者仍由 CA 信任锚用 SM2 签名问责。
