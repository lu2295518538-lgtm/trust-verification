# 生产就绪差距分析（现状 vs 实际投产）

> 本文回答：如果把本系统真正投产，它现在能直接运转吗？
> 结论：**密码学设计经得起推敲，但当前部署拓扑是演示级，不是生产级。** 以下结论均来自对 `core/chainmaker_client.py`、`app.py`、`config.py` 的逐行核对。

## 1. 链是真的，但跑在「一台虚拟机上的测试链」

`core/chainmaker_client.py` 真调长安链的 `cmc` CLI（`query block-by-height`、`invoke fact.save`、`get find_by_file_hash`），能真正上链、真正验证，**不是 mock**。

但 `CMC_PATH` / `SDK_CONFIG` 指向 `/home/ljh/chainmaker-go/test/chain1/...`，路径里的 `test/chain1` 表明这是 **VM 本地起的单节点测试链**。Flask 网页 + 链客户端 + 长安链节点三者全在同一台 VM 内，属单节点 / 单组织测试链，不是跨机构联盟链。

- 代码已解耦：`config.py` 的 `CMC_PATH` / `SDK_CONFIG_PATH` / `CHAIN_ID` 走环境变量。指向真实联盟链 SDK 配置即可接入多节点网络，**约束在部署/运维，不在代码**。

## 2. 并非「所有数据都在一条链上」

`api_submit` 一次提交做两件事：① `store_on_chain(...)` 上链；② `INSERT INTO commitments` 写本地 SQLite。

链上**只存证据指纹，不存原始数据**：

| 存哪儿 | 存了什么 | 没存什么 |
|---|---|---|
| 链上（`fact` 合约） | `file_hash`=SM3 指纹、`file_name`=DID、`file_content`=证据 JSON（指纹+承诺+签名+metadata） | 原始检疫记录 `raw_data` 全文 |
| 本地 SQLite（`data_store/chain.db`） | `raw_data` 全文、指纹、承诺、随机值、DID、tx_id、metadata | — |
| 服务端内存/客户端 | 水印图（embed 返回 base64，`verify_uploaded` 内存解码，服务端不落盘） | 水印照片持久化 |

这是**正确且合规的设计**：检疫记录含敏感 PII，不该明文上链。链是「防篡改锚点」，不是数据库。

**信任依赖**：`api_verify` 先查本地 SQLite 拿 `stored_fp`，再去链上比对。两者都对上才 `verified`。若本地库丢失，链上只能证明「该哈希曾存在」，无法复原记录本身。

## 3. 本地 SQLite 是单点（SPOF）

`app.py` 的 `DB_PATH = data_store/chain.db`（单文件 SQLite），无副本、无高可用。生产应二选一：换成可复制数据库（PostgreSQL/集群 SQLite），或明确「链是唯一真相源、本地只是索引」并提供从链重建索引的工具。

## 4. 提交是 fail-open（信任裂缝）

`app.py` 中若 `cmc` 调用失败，记录仍写入本地库、`tx_id` 留空、`step5_chainmaker.success=False`，但 `submit` 整体仍返回 `success=True`，失败进死信队列。对「可信验证」系统，**「链没存上也算成功」有风险**。投产前建议改 fail-closed：链没回执就明确报错。

## 5. 投产前需补齐的项

| 维度 | 现在（演示） | 投产需要 |
|---|---|---|
| 链网络 | 单机 `test/chain1` | 多组织联盟链（4 家机构各跑节点 + TBFT/Maxbft 共识） |
| CA | `issuer_ca.py` 本地生成并把私钥存 `ca_store.json` | 外部 CA 或 HSM 托管私钥 + 密钥轮换 |
| 水印图存储 | 服务端不落盘 | 如需「扫码即还原带水印原图」，需对象存储 / 链下库 |
| 可用性 | 单进程 Flask | 多实例 + 反向代理 + 链客户端连接池 |
| 密钥管理 | 明文配置 / `ca_store.json`（已 gitignore） | 密钥 vault / HSM |

## 6. 一句话总结

> 密码学是真的、链交互是真的，但现在是一台 VM 上的单机测试链 + 本地 SQLite，原始数据在本地库不在链上。要投产：换多组织联盟链（改环境变量即可接）、本地库做高可用或明确链为唯一真相源、CA 私钥进 HSM、提交改 fail-closed。
